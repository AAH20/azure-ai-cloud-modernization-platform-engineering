# Delivery roadmap

## Phase 1 — executable baseline

- Workload contract and deterministic 6R recommendation
- Unit economics and release gates
- Bicep and Terraform/OpenTofu foundation
- CI validation and evidence register

## Phase 2 — dependency intelligence

- Importers for CMDB, cloud inventory and flow logs
- Temporal application dependency graph
- Architecture decision records with provenance
- Scenario comparison and Monte Carlo sensitivity analysis

## Phase 3 — Azure platform product

- Management-group and subscription vending integration
- Hub-spoke and Virtual WAN profiles
- AKS and Container Apps workload modules
- Private data platform and model gateway
- Policy-as-code and automated operational verification

## Phase 4 — business operations

- Microsoft Fabric/Power BI semantic model
- Cost allocation and unit-cost telemetry
- Migration wave portfolio optimizer
- Measured customer case studies

## Definition of production-ready

Production-ready means the selected profile has passed security review, load and failure tests, recovery exercise, policy evaluation, cost guardrails, observability assertions, rollback and named-owner approval. Repository completeness alone cannot establish production readiness.
